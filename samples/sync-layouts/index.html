VAS WMS Sync — layout samples

Static mockups · no API · same 7 fake VAS types across both layouts for a fair comparison

Goal: make the screen simple and clean, while still letting you choose how you want to see diffs — that's the whole point of the Missing in WMS / Missing in config filters. Narrowed down to two finalists: A and D.
Layout A — List + detail — compact filterable type list on the left, one type's steps + a single merged instruction diff on the right. Nothing sprawls across the page at once. Layout D — Attention + compact rows — attention-strip filtering with expand-in-place detail, but the collapsed list is a compact single-row table (status pill + gap note in the same row as the VAS Type) instead of stacked cards.

Source: mock-data.js — 7 types covering every gap combination the real diff can produce (push-only, pull-only, reordered-but-identical, whole type missing each direction, fully aligned, not-yet-deployed).
