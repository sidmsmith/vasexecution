Theme
Today's desktop table (.steps-table) just gets shrunk on mobile — fixed-width columns force horizontal page scroll below ~992px, and there's no card view at all. These two mockups replace that with a genuine mobile-first card design; the desktop page is untouched. Both reuse the real VasConfig.renderStepContentHtml renderer, so every instruction block below has the exact bold/italic/underline/color/font-size/bullet-marker/image formatting it would have in production — nothing here is a formatting approximation.
Design A — Card-first (no outside reference)
Type cards → step accordion, instructions always inline, two levels of drill-down only. Design B — Supplier Enablement–aligned
Auth → oLPN → single-column po-card-item-style Type cards → tap opens its steps as the same nested cards on a normal screen, mirroring supplierenablement's auth/filter/card pattern. Design C — Refined (A + B combined)
B's flow and card style, with A's Type-header (title/subtitle + icon + status badge) and −/+ qty stepper — both the stepper and the complete button disappear once a step is done.
Testing on your phone: with the local dev server running (npm start), open http://192.168.86.90:3000/samples/execution-mobile-layouts/ from a phone on the same Wi-Fi. On a desktop browser, narrow the window or use devtools device emulation to see the phone-frame layout at native width — the frame itself is just a visual aid, both pages are ordinary responsive HTML underneath.
